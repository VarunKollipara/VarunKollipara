### 🦾 Vision-Guided Whiteboard Robot

A robotics and computer vision system that captures a whiteboard drawing, autonomously erases it, and recreates the original image using a UFACTORY Lite 6 robot arm.

- Detects drawing boundaries using AprilTags and OpenCV
- Extracts drawings into continuous paths using image skeletonization
- Maps 2D image coordinates into 3D robot space using stereo depth data
- Automates marker/eraser tool changes and multi-pass erasing

**Tech:** Python · OpenCV · AprilTags · ZED Stereo Vision · Robotics

[View Project](https://github.com/VarunKollipara/RoboticsFinalProject)
